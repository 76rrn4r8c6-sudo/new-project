# X10 Training OS

AI 기반 10m 공기권총 훈련 보조 및 경기력 향상 애플리케이션 프로토타입입니다.

## 구성

- 대시보드: 최근 훈련 기록, 준비도, 점수 추이, 반복 피드백
- AI 훈련일지: 날짜, 날씨, 컨디션, 정지훈련, 점수, 코치 피드백, 소감 저장
- 사격 기록: 6시리즈 기록 사격, 마무리 사격, X점 자동 요약
- 정지훈련 타이머: LOAD / START / STOP 음성 큐, 세트 진행, 화면 켜짐 요청
- 컨디션 체크인: 수면, 스트레스, 근육통, 기분 기록
- 인사이트 분석: 수면-점수 패턴, 주간 리포트, 반복 약점
- 코치 피드백: 태그 기반 타임라인과 검색

## 실행

브라우저에서 `index.html`을 열면 바로 실행됩니다.

데이터는 브라우저 로컬 저장소에 저장됩니다.
